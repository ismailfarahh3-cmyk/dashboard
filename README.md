# Daybook

A personal dashboard for habits and goals, gym lifts, boxing and cardio, body weight, and a nightly journal.

- `index.html` is the whole app: one self-contained page (HTML, CSS and JavaScript).
- Outside Claude it saves to the browser's localStorage. Inside Claude it saves to the viewer's private artifact database.
- Fonts load from Google Fonts (Young Serif, Nunito, Caveat).

## Run locally

Open `index.html` in a browser, or serve the folder:

    python3 -m http.server 8000
